# 🧬 Bioinformatics Sequence Analyzer

A Python-based web application for analyzing and visualizing biological sequences using Streamlit.

## 🚀 Live Demo

🔗 https://bioinformatics-sequence-analyzer-bit.streamlit.app/

---

## 📌 About the Project

The **Bioinformatics Sequence Analyzer** is an interactive web-based tool designed to perform basic and advanced analysis of biological sequences.

The project combines **Biotechnology, Bioinformatics, Python programming, data analysis, and visualization** into a single application.

It was developed as a practical learning project to understand how computational tools can be applied to biological sequence analysis.

---

## ✨ Features

### 🧬 DNA Sequence Analysis
- DNA sequence validation
- Sequence length calculation
- Nucleotide counting
- GC content calculation
- AT content calculation

### 📁 FASTA Analysis
- FASTA file handling
- Sequence extraction
- Sequence statistics
- Multiple sequence processing

### 🧪 Protein Analysis
- Protein sequence analysis
- Amino acid composition
- Protein statistics

### 🔬 Sequence Analysis
- Subsequence search
- Sequence comparison
- Similarity analysis
- DNA sequence processing

### 🧬 DNA → Protein
- DNA sequence translation
- Protein sequence generation
- Start/Stop codon analysis

### 🧫 Mutation Analysis
- Mutation detection
- Mutation position identification
- Sequence comparison
- Mutation visualization

### 📊 Visualization
- GC/AT content visualization
- Nucleotide composition
- Sequence statistics
- Graphical analysis

### 🌐 Biological Data
- NCBI-related sequence analysis
- Real biological sequence data handling
